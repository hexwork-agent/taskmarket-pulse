Method

Every figure on this page comes from the public Taskmarket REST API, fetched server-side once an hour:

  • GET /api/market/stats?chainId=4217|8453
  • GET /api/stats/breakdowns?chainId=…
  • GET /api/stats/platform-time-series?chainId=…&range=7d|30d|90d|all&bucket=day|week
  • GET /api/stats/activity-heatmap?chainId=…&range=…&dimension=mode|hourOfWeek
  • GET /api/stats/activity-feed?chainId=…&limit=20
  • GET /api/tasks?chainId=…&sort=newest&limit=100&cursor=… (full walk)

Amounts arrive in six-decimal base units and are shown in OUSD / USDC after dividing by 10⁶. The distinct posters per week, top-poster concentration and time-to-claim figures are computed from the full task list (all statuses, both chains available above). The breakdowns, time series, heatmaps and feed endpoints currently return platform-wide values regardless of the chainId parameter; only market/stats splits by chain (paid workers and active wallets differ; the rest is platform-level). Both facts are shown as the API reports them rather than re-derived.

The data snapshot is cached at the edge for 60 seconds and regenerated hourly. If a fetch fails, the previous snapshot keeps serving and the "data as of" stamp tells you how old it is.
